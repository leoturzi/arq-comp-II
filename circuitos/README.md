# Circuitos

Archivos `.circ` de [Logisim](https://logisim.app/).

- `UAL.circ`
- `multiplicador-2-bits.circ`

## Cómo abrirlos

Estos circuitos no se pueden ver embebidos en el repo: hay que
descargarlos a la máquina local y cargarlos en
[logisim.app](https://logisim.app/).

1. **File**
2. **Open**
3. **Local Desktop**
4. Seleccionar el archivo `.circ` descargado
